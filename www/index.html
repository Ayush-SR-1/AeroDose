Settings

ESP32 mode reads GET /api/telemetry and sends POST /api/valve (endpoint names are assumed; match your firmware). Browsers block http requests from an https page, so open this file over http on the same network.

Each edition keeps its own demo cylinder, tariff and usage history.

About

AeroDose measures what is left in a gas cylinder, closes the valve when cooking is done, warns at 20%, 10% and 2%, and locks on a leak or a jammed actuator.

This is a simulated dashboard. Real device firmware must enforce valve safety on its own; this page only sends commands and shows reported state.

Safety check before re-arming

The valve stays locked until every check is done and the live readings stay safe for 10 seconds.
